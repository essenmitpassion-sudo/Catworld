# VERSATZ Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. The owner explicitly requests autonomous inline execution without waiting for approvals.

**Goal:** Replace VEIL with a complete, minimal row-shifting strategy duel and reproducible evidence.

**Architecture:** Pure position transition plus immutable match history; bounded alpha-beta AI; vanilla DOM interface with worker and preview.

**Tech Stack:** Node24, JavaScript modules, esbuild, Playwright/installed Chromium.

**Spec:** docs/superpowers/specs/2026-11-15-rebirth-design.md

## Global Constraints

- 5×5; three equal pieces per side; no runtime network/backend.
- Complete step then target-row cyclic shift before evaluating victory.
- No simultaneous writers; checkpoint and authorized non-force Git push.
- Automated outcomes do not establish human enjoyment or solved balance.

## Review Focus

- Illegal/forged actions cannot mutate a match or saved replay.
- Intermediate gate visits must not win; transported opponents do not win out of turn.
- AI cancellation during undo/reset/reload cannot apply an obsolete move.
- Preview, animation and committed state agree at both wrapping edges.
- Draws, side switching and hotseat must function through complete real UI matches.
